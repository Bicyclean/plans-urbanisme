Raccourcis et astuces
  • Polygone : un clic par sommet ; double-clic ou Entrée pour terminer, Retour retire le dernier point, Échap abandonne. Les lignes (clôture, haie, terrain naturel…) restent ouvertes.
  • Rectangle : glissez. En façade, un simple clic pose un élément (fenêtre, porte, lucarne, portail…) à ses dimensions courantes.
  • Fenêtres et portes sur un mur (plan de masse, niveaux) : choisissez « Fenêtre (sur mur) » ou « Porte (sur mur) », puis cliquez sur le mur.
  • Modifier : double-clic sur un côté pour ajouter un sommet, glissez un sommet pour le déplacer, Suppr pour effacer, flèches pour décaler (Maj : ×10).
  • Copier / coller : Ctrl+C / Ctrl+V, aussi d’une vue à l’autre (un mur d’un niveau à l’autre, par exemple).
  • Annuler / rétablir : Ctrl+Z / Ctrl+Y.
  • Outils au clavier : V sélection, H main, P polygone, R rectangle, C cote, T texte, N niveau, S symbole.
  • Vue : molette pour zoomer, barre d’espace ou outil Main pour déplacer ; sur tablette, deux doigts.
  • Fond de plan : importez une image, « Mettre à l’échelle », cliquez deux points dont vous connaissez la distance et saisissez-la.
  • PDF : dans la fenêtre d’impression, « Enregistrer au format PDF », marges « Aucune », échelle 100 %.
  • DXF : export en mètres (1 unité = 1 m), un calque par type, textes sans accents ; import des lignes, polylignes, cercles, textes et cotes.
  • Sauvegarde : automatique dans ce navigateur ; « Enregistrer une copie » télécharge le dossier complet (.json, images comprises).

Cet outil aide à préparer les plans. Il ne garantit pas la conformité du dossier : vérifiez les pièces exigées auprès du service urbanisme de votre mairie.

Votre dossier n’est enregistré que dans ce navigateur. Gardez-en une copie : si l’historique est effacé, il serait perdu.
